# Документация проекта

## Описание базового синтаксиса записи и форматирования

Проект использует следующие технологии и синтаксис:

1. **Python**: Основной язык программирования для написания тестов.
2. **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
3. **Pytest**: Фреймворк для написания и запуска тестов.
4. **Allure**: Инструмент для генерации отчетов о выполнении тестов.

### Форматирование кода

- Код форматируется в соответствии с PEP 8 (стиль написания кода на Python).
- Используются docstrings для документирования методов и функций.
- Все шаги теста размечаются с помощью `@allure.step` или `with allure.step` для улучшения читаемости отчетов.

# Проект 1: Тестирование калькулятора с задержкой
## Описание
Проект содержит автоматизированные тесты для проверки работы веб‑калькулятора с задержкой, расположенного по адресу:
https://bonigarcia.dev/selenium-webdriver-java/slow-calculator.html

Цель теста — убедиться, что калькулятор корректно вычисляет сумму 7 + 8 с заданной задержкой (45 сек) и возвращает результат 15.

## Структура проекта

calculator_page.py — класс‑страница для взаимодействия с калькулятором;
test_calculator.py — тестовый класс с проверкой вычисления 7 + 8;
requirements.txt — файл с зависимостями.

## Требования:
- Python 3.8+;
- Google Chrome (или другой браузер с поддержкой WebDriver);
- ChromeDriver (или соответствующий драйвер для выбранного браузера);
- Установленные пакеты из requirements.txt

# Проект 2: Тестирование процесса покупки на saucedemo.com
## Описание
Проект содержит автоматизированные тесты для проверки процесса покупки на сайте:
https://www.saucedemo.com/

Цель теста — пройти полный цикл покупки: авторизация → выбор товаров → корзина → оформление заказа → проверка итоговой суммы.

## Структура проекта
page_objects.py — классы‑страницы для взаимодействия с элементами сайта;
test_purchase.py — тестовый класс с проверкой полного цикла покупки;
requirements.txt — файл с зависимостями проекта.

## Требования:
- Python 3.8+;
- Firefox (или другой браузер с поддержкой WebDriver);
- GeckoDriver (для Firefox) или соответствующий драйвер для другого браузера;
- Установленные пакеты из requirements.txt

# Инструкция по запуску тестов для формирования отчета Allure

1. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите тесты с генерацией отчета Allure:
   ```bash
   pytest --alluredir=./allure-results
   ```

   Эта команда запустит все тесты и сохранит результаты в директорию `./allure-results`.

# Инструкция по просмотру сформированного отчета Allure

1. После завершения тестов, чтобы просмотреть отчет, выполните команду:
   ```bash
   allure serve ./allure-results
   ```

   Эта команда запустит локальный сервер и откроет отчет в браузере.

2. В отчете Allure вы увидите:
   - **Название теста**: Например, `Проверка результата вычисления 7 + 8`.
   - **Описание теста**: Описание, тест проверяет, что калькулятор корректно вычисляет сумму 7 + 8 с задержкой 45 секунд
   - **Шаги теста**:
     - Открытие страницы калькулятора
     - Создание объекта страницы калькулятора
     - Установка задержки на 45 секунд 
     - Нажатие кнопок: 7, +, 8, =
     - Получение результата вычисления
     - Проверка результата: ожидаемое '15', полученное '15'
   - **Результат**: Успешное выполнение или ошибка с указанием ожидаемого и фактического результата.
